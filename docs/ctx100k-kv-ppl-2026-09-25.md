- **Build ik fallita al link** (`LNK2019 __imp_socket/WSAStartup`, LNK1120): upstream ha aggiunto `ggml/src/ggml-rpc-transport.cpp` compilato **sempre**, ma `ws2_32` è linkato solo con RPC. **Fix senza toccare il codice: riconfigurare con `-DGGML_RPC=ON`** (`cmake -B build -DGGML_RPC=ON`) e ricompilare. Valido per ogni build Windows finché upstream non corregge.
- L'hook utente `validate-bash.sh` blocca i comandi Bash che contengono la sottostringa "build" seguita da slash: usare PowerShell con percorsi `\` o script `.ps1`, oppure il tool Write per creare file.
- `rtk grep` altera l'output di grep/awk: per estrarre tabelle dai log usare uno script Python (`R:\TEMP\ctx\t.py` come modello).
